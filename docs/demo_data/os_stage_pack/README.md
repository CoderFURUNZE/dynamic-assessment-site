# 操作系统三阶段画像测试数据包

## 1. 数据包用途
用于测试“教师分阶段导入数据 -> 系统生成阶段画像 -> 学期末汇总最终画像与参考分”的完整链路。

## 2. 适用前提
1. 已有课程：`操作系统`（课程编码建议为 `OS`）
2. 已有知识点：
- `OS-1` 操作系统的历史
- `OS-2` 进程与线程
- `OS-3` 内存管理
- `OS-4` 文件管理
3. 已有学生账号：`student1`、`student2`、`student3`
4. 老师端已创建 3 个阶段：
- 阶段1：基础认知
- 阶段2：结构理解
- 阶段3：综合应用

## 3. 文件说明
每个阶段包含 6 份 CSV：
- `video`：视频学习记录
- `assignment`：作业完成记录
- `quiz`：小测成绩记录
- `attendance`：考勤记录
- `task`：任务完成记录
- `participation`：课堂参与记录

## 4. 建议导入顺序
### 阶段1
1. `stage1_video.csv`
2. `stage1_assignment.csv`
3. `stage1_quiz.csv`
4. `stage1_attendance.csv`
5. `stage1_task.csv`
6. `stage1_participation.csv`

### 阶段2
按同样顺序导入 `stage2_*.csv`

### 阶段3
按同样顺序导入 `stage3_*.csv`

## 5. 建议的测试观察对象
### student1
- 整体表现一直较强
- 学习投入、学习成效较高
- 学期末画像应偏稳定优秀

### student2
- 阶段1一般，阶段2提升，阶段3明显进步
- 更适合观察“动态变化”和“期末汇总是否比阶段1更好”

### student3
- 学习不稳定
- 出勤、任务完成、成绩都偏弱
- 更适合观察风险识别和期末低分参考

## 6. 老师补评分建议
除了导入 CSV，建议你在每个阶段给学生补几项老师评分，验证“老师主观判断进入画像链路”：

可补：
- 创造性思维倾向
- 协作能力与社交网络
- 学习动机与态度
- 自我调节与元认知
- 跨情境迁移能力

补评分建议见：`teacher_feedback_reference.md`

## 7. 期望测试结果
1. 导入阶段1后，三名学生会出现明显差异
2. 导入阶段2后，`student2` 应该出现上升趋势
3. 导入阶段3后，系统应能给出学期末汇总结果
4. `student1` 的期末参考分应高于 `student2`
5. `student3` 的风险提示应最明显

## 8. 扩展测试（可选）
如果你想测试更完整的学期累计效果，可以再创建第4阶段，例如：总结提升，并继续导入 `stage4_*.csv`。
