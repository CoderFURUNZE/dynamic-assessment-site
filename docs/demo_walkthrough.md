# 动态评价系统演示与验收路径

## 1. 主线演示顺序
1. 管理员登录，确认课程、教师、学生基础数据和画像规则已经存在。
2. 教师登录，进入 `阶段管理` 创建课程阶段。
3. 教师进入 `阶段数据导入` 上传样例数据，触发阶段画像和动态评价更新。
4. 教师进入 `图谱工作台` 查看知识图谱，并确认节点已绑定资源、任务、练习或小测。
5. 教师进入 `学习分析` 查看班级阶段分析、风险学生、薄弱知识点和进度排行。
6. 教师进入 `单学生详情` 查看成长轨迹，并为某阶段填写教师补充评价。
7. 学生登录，进入 `课程总览` 查看当前阶段概览和阶段趋势。
8. 学生进入 `知识图谱` 打开全屏工作区，点击节点查看资源、任务、练习和小测内容。
9. 学生生成学习建议，查看推荐依据、补救路径和解锁状态。
10. 学生进入 `学习报告` 查看画像结果、阶段变化和教师补充评价。

## 2. 讲解重点
- 动态评价：核心在于“教师按阶段导入数据后，系统更新阶段结果和总画像”。
- 学习者画像：当前主线以学习行为与学习状态画像为主，不以多元智能为核心。
- 知识图谱：图谱不仅展示知识结构，还承担资源挂载、节点学习和推荐支撑。
- 推荐机制：先决定该补哪个知识点，再根据画像决定怎么推。

## 3. 扩展项说明
以下功能本轮只做占位，不纳入 V1 主线验收：
- 多元智能问卷
- 自评与互评
- 知识图谱截图识别生成

可在管理员端或教师端的 `扩展与答辩` 页面查看占位说明。

## 4. 空状态处理
- 如果学生端没有课程或知识点：先在管理员端或教师端完成课程和知识点建设。
- 如果没有阶段评价结果：先在教师端创建阶段并导入数据。
- 如果图谱节点没有内容：先在教师图谱工作台绑定资源、任务、练习或小测。
- 如果没有推荐结果：先选择知识点并点击 `生成学习建议`。

## 5. 交付检查清单
- 教师可以创建阶段并导入数据。
- 系统可以生成学生画像与阶段评价。
- 教师可以查看班级分析和单学生详情。
- 教师可以保存阶段补充评价。
- 学生可以查看课程总览、知识图谱节点内容、推荐建议和学习报告。
- 扩展功能有独立占位页，不干扰主线演示。
