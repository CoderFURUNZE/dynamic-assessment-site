# 动态评价系统联调测试清单

## 目标
本清单用于对当前系统的三端主链路进行联调验证，优先发现并修复影响演示、验收和答辩的阻塞性问题。

快速方式：
- 先执行接口级冒烟脚本：`./.venv/bin/python backend/scripts/smoke_acceptance.py`
- 再按本清单做页面级人工联调。

联调重点不是覆盖所有边角功能，而是确保以下主线可完整跑通：

1. 管理员准备基础数据
2. 教师构建知识图谱并维护课程内容
3. 教师导入阶段数据
4. 系统生成学习者画像与动态评价
5. 学生查看图谱、报告和推荐

## 七、当前已知高风险点

以下问题在联调中需要重点关注：

1. 后端分析接口中的模型导入遗漏
- 典型症状：`NameError`
- 重点接口：`/api/admin/analytics/student-detail`

2. 教师图谱工作台前端计算属性错误
- 典型症状：页面卡住、长时间 loading

3. 教师历史课程归属缺失
- 典型症状：教师看不到课程或访问课程相关操作时 403

4. 图谱页面布局问题
- 典型症状：舞台下沉、留白过多、颜色割裂

7. 前端关键页面无长时间 loading、白屏或明显结构错乱
