# 动态评价系统联调测试清单

## 目标
用于验证当前系统三端主链路是否可稳定演示，重点覆盖课程、图谱、阶段导入、画像与分析。

## 环境检查
- [ ] MySQL 已启动并可连接
- [ ] 后端可访问 `/health`
- [ ] 前端可访问登录页
- [ ] 管理员、教师、学生账号均可登录

## 管理端
- [ ] 可查看用户列表
- [ ] 可查看课程列表
- [ ] 可访问 `/api/admin/analytics/overview`

## 教师端
- [ ] 可查看教师课程列表
- [ ] 可查看课程阶段列表
- [ ] 可下载阶段导入模板
- [ ] 可导入阶段数据
- [ ] 可查看教师分析结果

## 学生端
- [ ] 可查看已选课程
- [ ] 可查看知识图谱
- [ ] 可查看学习画像
- [ ] 可查看推荐与学习报告

## 动态评价主链路
- [ ] 教师创建阶段
- [ ] 教师导入阶段数据
- [ ] 系统生成阶段评价快照
- [ ] 学生画像同步更新
- [ ] 教师分析页可见变化
- [ ] 学生报告页可见变化

## 回归方式
优先执行：
```powershell
py -3.11 .\backend\scripts\smoke_acceptance.py
```
