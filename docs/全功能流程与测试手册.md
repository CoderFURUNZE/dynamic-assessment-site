# 动态评价系统全功能流程与测试手册

## 1. 文档用途
本手册用于你本人做全量手工测试。  
你按本文档步骤执行，把问题记录到 `docs/测试问题记录.md`，我再按记录逐项修复。

---

## 2. 测试前准备

### 2.1 环境与服务
1. 启动后端（FastAPI）
2. 启动前端（Vue）
3. 打开系统登录页

### 2.2 默认账号
- 管理员：`admin / admin123`
- 教师：`teacher1 / teacher123`
- 学生：`student1 / student123`

### 2.3 推荐基线数据
优先使用以下演示数据，保证“阶段评价+画像”可观察：
- `docs/demo_data/cn_stage_pack/`
- 导入说明：`docs/demo_data/cn_stage_pack/README.md`

---

## 3. 系统整体流程（先理解再测）
完整业务主链：

1. 管理员准备基础数据  
2. 教师设置课程评价项与阶段  
3. 教师导入阶段数据（视频/作业/小测/考勤/任务/参与）  
4. 系统生成阶段评价与画像摘要  
5. 教师查看班级分析与单学生详情  
6. 学生查看图谱、学习资源、练习小测、报告与建议  
7. 教师/管理员根据问题继续调整配置并重算

---

## 4. 测试执行顺序（强制按顺序）

### 阶段 A：基础可用性（冒烟）
- A-01 登录页可正常登录三角色
- A-02 三角色首页可进入且无报错白屏
- A-03 关键接口已通过冒烟（执行 `backend/scripts/smoke_acceptance.py`，报告会生成到 `logs/` 目录）

通过标准：A 阶段全通过再进入 B。

### 阶段 B：管理员流程
目标：验证“系统可配置、可治理、可重算”。

1. 用户管理
- 新增/编辑/删除教师和学生
- 校验权限、状态、异常提示

2. 课程管理
- 新增课程并绑定教师
- 编辑课程信息，确认教师端仅看到已绑定课程

3. 知识点与关系
- 新增知识点
- 维护 `prerequisite` / `related` 关系
- 删除关系后图谱应同步变化

4. 资源/题库绑定
- 知识点绑定资源、题目/小测
- 学生端节点详情可见

5. 画像规则与指标池
- 维护一级维度和二级指标
- 维护来源类型（`auto`/`teacher`/`questionnaire`）
- 调整权重后保存成功

6. 分析与重算
- 触发重算画像
- 查看画像分布、风险学生、薄弱知识点
- 人工覆盖画像后验证优先级生效

通过标准：管理员可完成“配置-重算-查看结果”闭环。

### 阶段 C：教师流程
目标：验证“教师可独立完成阶段评价与图谱维护”。

1. 课程与指标选择
- 选择课程
- 勾选课程评价项并保存

2. 阶段管理
- 新建第 1/2/3 阶段
- 修改阶段顺序和时间

3. 阶段数据导入
- 按类型导入 CSV/Excel
- 校验成功数/失败数/错误明细

4. 图谱工作区（重点）
- 进入全屏图谱工作区
- 左侧：树状导航、搜索、分类筛选可用
- 中间：节点可拖动，拖动后仍在可视区域
- 右侧：节点详情显示完整（资源/任务/练习/小测/关系）
- 图内编辑：新增知识点、关系维护、内容绑定

5. 教师分析与学生详情
- 班级画像分布、阶段趋势、风险清单可展示
- 单学生详情：阶段变化、教师补充评价、学习记录可展示

6. 报名审核独立页
- 进入 `/teacher/enrollments`
- 只看当前教师所属课程的报名申请
- 可直接通过/拒绝，学生端报名状态和站内通知同步变化

7. 最终评分确认页
- 进入 `/teacher/final-review`
- 选择学生后查看阶段趋势、期末雷达图、系统期末参考分
- 填写推荐链路收口说明与老师确认意见
- 保存后再次进入可回显已确认结果

通过标准：教师端可独立完成“建阶段-导数据-看结果-调图谱-报名审核-最终评分确认”。

### 阶段 D：学生流程
目标：验证“学生端简单可懂、能完成学习闭环”。

1. 总览
- 当前画像、评价等级、学习建议展示正常

2. 图谱学习
- 可进入全屏图谱
- 圆形节点点击显示资源学习内容
- 方形分类节点点击显示总览信息
- 三栏联动正常（左筛选、中画布、右详情）

3. 资源/小测/练习
- 资源可打开
- 小测可提交
- 练习可提交并生成记录

4. 补充问卷
- 可填写并保存
- 保存后结果可在报告页同步体现

5. 学习报告
- 显示阶段趋势、画像摘要、建议说明

6. 推荐链路最后收口
- 进入 `/student/kp-content/:kpId`
- 完成资源/练习/小测后，页面显示“推荐链路最后收口”状态
- 可从收口区进入下一推荐点，或回到学习报告查看结果

通过标准：学生能完成“看图谱-学资源-做题-推荐收口-看报告”闭环。

### 阶段 E：联动与边界
目标：验证稳定性与容错。

1. 无课程/无知识点空状态提示清晰
2. 无阶段数据时提示“先建阶段再导入”
3. 数据导入字段缺失时有友好报错
4. 角色越权访问应返回无权限
5. 页面刷新后状态恢复合理（课程、阶段、节点）
6. 多次进入全屏图谱不应白屏/无限加载
7. 报名审核和最终评分独立页可重复进入且状态回显正常

通过标准：无阻塞缺陷（P0/P1），主要流程可连续演示。

## 5. 测试记录规则（你执行时照这个做）

### 5.1 每条问题必须包含
1. 角色（管理员/教师/学生）
2. 页面路径（例如 `/teacher/graph-workspace`）
3. 操作步骤（最少 3 步）
4. 实际结果
5. 期望结果
6. 截图（建议）
7. 控制台/后端报错（如有）

### 5.2 问题优先级
- `P0`：系统不可用/主流程中断
- `P1`：核心功能异常但可绕过
- `P2`：体验问题/文案问题/UI错位
- `P3`：建议优化
