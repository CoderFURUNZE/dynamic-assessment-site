# 验收回归执行说明

## 1. 目的
这份说明用于快速验证三端主链是否正常，避免每次改动后只能手工点页面。

脚本位置：
- `backend/scripts/smoke_acceptance.py`

它会检查：
1. 后端健康检查
2. 管理员/教师/学生登录
3. 三角色基础接口可用性
4. 教师阶段与画像配置接口
5. 学生图谱地图与节点详情接口（有课程数据时）
6. 页面级回归仍需手工补测：`/teacher/enrollments`、`/teacher/final-review`、`/student/kp-content/:kpId`

---

## 2. 前置条件
1. 后端已启动：`http://127.0.0.1:8000`
2. 数据库可用
3. 至少有默认账号（`admin/teacher1/student1`）

---

## 3. 执行命令
在项目根目录执行：

```bash
./.venv/bin/python backend/scripts/smoke_acceptance.py
```

可选参数（示例）：

```bash
./.venv/bin/python backend/scripts/smoke_acceptance.py \
  --base-url http://127.0.0.1:8000 \
  --admin-user admin --admin-pass admin123 \
  --teacher-user teacher1 --teacher-pass teacher123 \
  --student-user student1 --student-pass student123
```

自定义报告输出路径：

```bash
./.venv/bin/python backend/scripts/smoke_acceptance.py --output logs/my_smoke_report.md
```

---

## 4. 输出结果说明
脚本结束后会输出：
1. 通过/失败统计，例如 `21/21 passed`
2. 报告文件路径，例如 `logs/smoke_acceptance_20260312_212000.md`

报告里每条用例都有：
- `PASS/FAIL`
- 对应接口或校验项
- 失败时的状态码或错误详情

---

## 5. 建议执行时机
建议在以下时机执行一次：
1. 合并到主分支前
2. 改了后端路由或权限逻辑后
3. 改了图谱相关页面后
4. 改了报名审核、最终评分确认或推荐收口相关页面后
5. 导师演示/答辩前
